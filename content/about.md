I'm Yuchen, a software engineer specializing in backend systems, platform engineering and security infrastructure. I like taking a messy, complex problem, simplifying it, and turning it into a system that is easy to maintain.

I started out in security. I studied Information Security in college, interned in web penetration testing and Active Directory security, and then came to the U.S. for graduate school. My first full-time role was as a cloud security operations engineer. Finding problems was interesting, but I wanted to be the one fixing them, so I moved into a software engineering role in the same department.

That background shapes how I build: security isn't a separate team's job, it's part of the software development lifecycle. Today I write backend services and platform tooling.

## What I work on

- **Backend systems**: APIs and services in Python, FastAPI and Go, backed by SQL databases
- **Platform engineering**: CI/CD with GitHub Actions, Docker, cloud deployment
- **Security infrastructure**: secret scanning, attack-surface monitoring, secure-by-default tooling
- **Applied AI**: agent-based tools and the machine learning fundamentals behind them

## Outside work

I build side projects like a [live NYC commuter-transit map](/projects/greater-ny-transit/), rebuild tools such as Redis and a DNS server from scratch to learn how they work, and write about what I learn on [my blog](/posts/).
